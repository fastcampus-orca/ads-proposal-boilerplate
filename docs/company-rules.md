# 업무 사규

바른그로스의 가상 제공본입니다. 세율·수수료는 이 연습의 계산 전제이며 실제 매체 청구나 세무 처리에 관한 안내가 아닙니다.

## 적용 범위

- 적용할 업무: 브리프 분석, 광고 제안·견적 작성, 독립 평가와 수정

## 작업·검토 기준

| 적용 상황 | 연결된 회사 소개서 항목 | 지킬 행동 | 결과물에서 확인할 내용 |
| --- | --- | --- | --- |
| 고객 조건 해석 | 조건 준수 | 브리프의 목표·기간·총액·매체·정산 조건을 보존한다. | 원문 위치와 조건의 일치 |
| 견적 산정 | 비용 투명성 | 순매체비 M을 기준으로 수수료 F=원 단위 반올림(M×15%)를 구한다. | 기준금액·요율·금액과 포함 업무 |
| 세금·총액 산정 | 비용 투명성 | 월 공급가액 S=M+F, VAT V=원 단위 반올림(S×10%), 청구액 T=S+V로 계산한다. | 월별 계산과 월 청구액 합으로 구한 계약 총액 |
| 매체 배분 | 비용 투명성 | 배분은 세전 순매체비 기준으로 하고 마지막 매체에 원 단위 잔액을 배정한다. | 매체 합계=M, 비율 합계=100% |
| 기대 성과 | 근거 중심 | 클릭=M÷CPC, 전환=클릭×CVR, CPA=M÷전환, ROAS=매출÷M×100으로 계산한다. 매체별로 계산한 뒤 합산한다. | 수수료·VAT를 제외한 동일한 분모, 중간값을 반올림하지 않은 계산 |
| 표현·출처 | 정직한 표현 | 제공 가정과 실측을 구분하고 목표를 보장하지 않는다. | 가정의 원문 위치, 미달 구간과 대응, 효능·비교 우위 근거 |
| 업무 검토 | 조건 준수 | 작성과 평가를 분리하고 수정 후 전 항목을 다시 평가한다. | 평가 대상과 최종본의 일치, 실제 라운드 기록 |

반올림은 양수의 0.5 이상 올림(ROUND_HALF_UP)이다. 수수료는 월 합산 매체비에 한 번, VAT는 월 합산 공급가액에 한 번 적용하며 매체별 세액을 따로 반올림하지 않는다. 3개월 세액은 월 세액을 합한다. 성과 표시만 마지막에 전환수 소수 둘째 자리, CPA 원 단위, ROAS 소수 첫째 자리로 반올림하고 계산에는 반올림 전 값을 사용한다.

수수료에는 전략 수립, 초기 세팅, 제공 이미지 기반 월 4종 소재 기획, 주간 최적화, 주간·월간 보고가 포함된다. 촬영·상세페이지 제작·추가 매체 집행은 포함하지 않으며, 승인 없는 추가 청구는 없다.

## 사용자 확인이 필요한 일

- 확인할 상황: 예산·기간·수수료율·업무 범위 변경 또는 상충하는 입력
- 확인할 내용: 충돌한 원문, 계산 영향, 필요한 결정

## 기준 충돌과 예외

- 기준이 충돌할 때: 임의로 조건을 완화하지 않고 사용자에게 확인
- 예외를 허용할 조건: 승인된 변경과 적용 범위를 기록하고 기준을 다시 확정하고 이전 기록을 보존한 경우

## 상황별 적용

| 업무 상황 | 선택할 행동 | 적용한 기준 |
| --- | --- | --- |
| 월 예산에 수수료·VAT가 포함됨 | 회사 산식으로 순매체비를 역산하고 청구액을 다시 더한다. | 비용 투명성 |
| 과거 실적이 없음 | 제공된 가정으로만 계산하고 실측 갱신 시점을 적는다. | 근거 중심 |
| 예상 성과가 목표보다 낮음 | 목표는 유지하고 차이와 대응을 명시한다. | 정직한 표현 |

## 아직 정할 내용

- 실제 계약의 과세·청구 조건은 계약 전 별도 확인
