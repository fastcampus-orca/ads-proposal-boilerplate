# 업무 사규

> 1인 광고 운영 대행사 바른그로스의 가상 사규입니다. 고객사의 사규가 아니며 제안·견적서를 작성하고 평가할 때 함께 적용합니다.

## 적용 범위

- 적용할 업무: 고객 브리프 분석, 광고 운영 제안·견적 작성, 독립 평가와 수정

## 작업·검토 기준

| 규칙·연결된 가치 | 지킬 행동 | 결과물에서 확인할 내용 |
| --- | --- | --- |
| R1 조건 준수 | 브리프의 제품·고객·목표·매체·예산·기간·정산·보고 조건을 정확히 반영한다. | 원문과 제안의 숫자·조건, 필수 내용의 누락 여부 |
| R2 비용 투명성 | 금액의 부가세 포함 여부를 명시하고 광고비·수수료·세액을 나눠 월 합계와 계약 총액을 검산한다. | 매체별 금액·비율, 세액 계산, 총액, 성과 계산에 사용한 순수 광고비 |
| R3 가격 근거 | 수수료율의 기준금액 또는 단가·수량과 계산식, 포함 업무·추가 비용 여부를 밝힌다. | 제시 금액을 다시 계산할 수 있는 산정식과 업무 범위 |
| R4 근거 중심 | 근거 없는 수치를 쓰지 않고 제공 정보는 원문, 외부 자료는 출처·확인일, 추정은 가정·계산식·검증 계획을 붙인다. | CPC·전환율·예상 성과의 근거, 계산 정확성, 목표와 예상의 차이 |
| R5 정직한 표현 | 성과 보장과 미확인 효능·비교 우위 표현을 금지하고 간결한 비즈니스 문체를 쓴다. | 제안 본문·카피의 단정 표현, 가정을 확정 사실처럼 쓴 문장 |
| R6 독립 검토 | 작성과 평가를 분리하고 반려된 문서는 수정 후 전 항목을 재평가한다. | 라운드별 초안·평가·통과 개수, 통과본과 평가 대상의 일치 |

## 사용자 확인이 필요한 일

- 확인할 상황: 브리프의 예산·기간·수수료율 변경이나 회사 사규와 충돌하는 요구
- 확인할 내용: 충돌한 원문, 계산에 미치는 영향, 결정이 필요한 조건

## 기준 충돌과 예외

- 기준이 충돌할 때: 고객 조건이나 사규를 임의로 완화하지 않고 사용자에게 확인
- 예외를 허용할 조건: 사용자가 변경한 업무 조건과 적용 범위를 기록한 경우이며, 허위 수치나 성과 보장을 허용하는 근거로 쓰지 않음

## 상황별 적용

| 업무 상황 | 선택할 행동 | 적용한 기준 |
| --- | --- | --- |
| 월 총예산에 수수료와 세금도 포함됨 | 순수 광고비를 역산하고 총액을 다시 확인 | R2·R3 |
| 과거 캠페인 데이터가 없음 | CPC·전환율을 가정으로 표시하고 실측 갱신 계획 제시 | R4 |
| 고객이 확정 매출을 요구함 | 보장 대신 목표·가정·개선 방안을 설명 | R5 |

## 아직 정할 내용

- 실고객 계약에 적용할 가격 정책은 별도 확정하며, 본 실습의 세율은 브리프에 명시한 가상 계산 전제를 사용
