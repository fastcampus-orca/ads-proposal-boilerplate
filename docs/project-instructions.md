# 프로젝트 작업 지침

포커스온의 광고 제안·견적 업무에 적용하는 지침입니다.

## 입력과 업무 범위

- 회사 소개서와 업무 사규를 읽고 대행사와 고객사를 구분한다.
- 브리프에서 목표·계약 조건·제출 내용을 확인한다. 문서 저장 위치는 [README](../README.md)를 따른다.
- 작성에 필요한 조건이 부족하거나 상충하면 원문과 영향을 제시해 확인한다. 계정 기능 등 집행 전 확인 사항은 확인 계획으로 분리한다.

## 제안·견적 작성

- 브리프·회사 문서·제안 및 견적 양식에 맞춰 전략과 비용을 작성한다.
- 기대 성과는 제공 가정과 순매체비로 계산한다. 제품 특징을 근거 없는 효능이나 경쟁 우위로 확대하지 않는다.
- 예산·기간·수수료율·업무 범위를 임의로 변경하지 않는다.

## 결과 검토

- 사규의 산식으로 검산하고 원문 위치·재계산 결과·수정 전후의 변화를 기록한다.
- 최종 확정 조건은 [공통 지침](../AGENTS.md#산출물과-저장)을 따른다. 미충족 항목은 사유와 필요한 수정을 남긴다.
- 예상 성과와 검토 결과는 실제 집행 성과나 계약 승인을 대신하지 않는다.
