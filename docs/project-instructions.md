# 프로젝트 작업 지침

바른그로스 광고 제안 업무에 적용하는 가상 제공본입니다.

## 적용 범위

- 회사·활동: 바른그로스
- 적용할 업무: 무브펫 광고 제안·견적 작성과 교차 검증

## 작업 시작

- 회사 소개서와 업무 사규를 읽고 대행사와 고객사를 구분한다.
- 브리프에서 목표·입력·제출 내용을 확인한다. 문서 저장과 역할별 전달 규칙은 루트 README를 따른다.
- 필요한 정보가 부족하거나 상충하면 원문과 영향을 제시한다.

## 작업 진행

- Codex 작성자는 브리프·회사 문서·제안 및 견적 양식으로 작성한다.
- Claude Code 평가자는 요구사항과 8개 체크리스트를 만들고 고정한 뒤 독립 평가한다.
- 작성자는 체크리스트·요구사항 정리·전체 평가를 읽지 않는다. 수정 시 자기 초안과 반려 사유·수정 요청만 받는다.
- 기대 성과는 제공 가정과 순매체비로 계산한다. 제품 특징을 근거 없는 효능이나 경쟁 우위로 확대하지 않는다.

## 결과 검토

- 작성자는 사규 기준으로 자체 확인하고 제출한다. 평가자는 원문 위치·재계산·이전 대비 변화를 기록한다.
- 평가 결과가 모두 Y인 제안서만 최종본으로 확정한다. 실제 집행 성과나 사람의 계약 승인을 대신하지 않는다.

## 판단이 필요한 상황

- 입력 조건 변경은 사용자에게 확인한다. 3라운드 뒤에도 N이 남으면 미해결 사유와 필요한 결정을 보고한다.
- 첫 라운드 통과는 그대로 기록한다. 별도 연습이 필요하면 실제 결과와 분리한 연습용 재현 요청을 따른다.
