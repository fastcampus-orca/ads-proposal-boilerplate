# 회사 소개서

## 회사와 고객

- 회사·활동명: 포커스온
- 하는 일: 소형 온라인 브랜드의 광고 전략·소재 기획·매체 운영·성과 보고
- 우선 고객: 첫 유료 광고를 시작하는 소형 온라인 브랜드
- 해결할 문제: 광고비·수수료·세금과 기대 성과를 함께 비교하기 어려운 문제
- 고객의 현재 해결 방법: 대표가 직접 광고를 시험하거나 대행 견적을 비교
- 우리를 선택할 이유: 계산 과정과 가정, 업무 범위와 개선 계획을 공개

## 존재 이유와 비전

- 비전 한 줄: 작은 브랜드도 이해하고 결정할 수 있는 광고 운영
- 존재 이유: 고객이 비용과 불확실성을 알고 광고를 시작하도록 돕기
- 만들고 싶은 변화: 매출 약속보다 확인 가능한 근거로 대행사를 선택하는 관계

## 핵심 가치

| 가치 | 실제 업무에서 지킬 행동 |
| --- | --- |
| 조건 준수 | 고객의 예산·기간·목표를 임의로 바꾸지 않기 |
| 비용 투명성 | 순매체비·수수료·세금과 계산식을 분리하기 |
| 근거 중심 | 제공 정보·가정·실측치를 구분하기 |
| 정직한 표현 | 성과 보장과 미확인 제품 효능을 약속하지 않기 |

## 우선순위와 지양점

- 기준이 충돌하는 상황: 수주에 유리한 표현이 근거보다 강한 성과 약속이 되는 경우
- 우선할 기준과 이유: 고객이 비용과 불확실성을 판단하도록 근거를 우선
- 피할 일·표현·약속: 매출 보장, 출처 없는 업계 평균, 숨긴 추가 비용, 확인되지 않은 비교 우위

## 아직 정할 내용

- 실제 고객 계약 여부와 광고 계정 접근은 이번 제안 범위 밖이며, 실집행 전 별도로 확정
