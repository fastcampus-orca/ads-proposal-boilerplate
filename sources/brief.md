# 무브펫 광고 의뢰 브리프

포커스온 담당자가 무브펫의 광고 의뢰 내용을 정리한 내부 문서입니다. 이 자료와 회사 사규를 바탕으로 무브펫에 전달할 광고 제안서·견적서를 작성합니다.

## 회사와 제품

- 고객사: 무브펫 공식스토어, 반려동물 리빙용품을 판매하는 소형 스마트스토어
- 담당자: 김소미 대표
- 제품: 무브펫 서큘 자동급수기 Circle 2.0
- 판매가: 39,000원, 필터 2입 포함
- 출시 상태: 신규 등록 예정이며 판매·리뷰·과거 광고 실적 없음
- 제공 제품 정보: 4단계 정수 필터, 2L 용량, 원터치 분리 구조, 일부 부품 식기세척기 세척 가능
- 필터 교체 주기 60일은 제공된 관리 가정이며 사용 환경에 따라 달라짐. 물 교체·세척을 대체한다는 뜻이 아님
- 경쟁사 성능·가격 비교 근거는 제공하지 않음. 효능·배송·경쟁 우위를 새로 만들지 말 것

## 고객과 메시지

- 1차 고객: 수도권의 25~45세 여성 반려묘·반려견 보호자, 온라인 반려용품 구매자
- 2차 고객: 다묘·다견 가정, 맞벌이·1인 가구
- 고민: 물 관리와 제품 세척의 번거로움
- 제외할 방향: 반려동물과 무관한 일반 가전 관심층까지 무차별 확장
- 따뜻하고 신뢰감 있는 간결한 문체. 공포·질병 예방·치료 암시, 미확인 효능, 성과 보장 금지

## 목표와 매체

- 목표 CPA: 순매체비 기준 구매 전환당 15,000원 이하
- 보조 목표: 순매체비 기준 ROAS 250% 이상, 신규 구매 고객 비중 70% 이상
- 목표는 유지하되 월별·누적 예상치와 구분하고 미달 구간은 차이·개선 조치를 명시할 것
- 신규 고객 비중은 추정할 근거가 없으므로 목표만 제시하고 구매 이력으로 확인할 계획을 적을 것
- 지정 매체: 네이버 검색광고·GFA, 메타 페이스북·인스타그램 피드·스토리
- 1개월차 인지도·트래픽 확보, 2~3개월차 전환 최적화. 매체별 역할·캠페인 유형·타겟·배분 이유는 제안할 것
- 타겟팅·전환 추적 기능은 실제 계정에서 이용 가능 여부를 확인해야 한다는 전제로 전략을 제시할 것

## 예산과 계약

| 항목 | 확정 조건 |
| --- | --- |
| 월 청구 총액 | 3,000,000원, 순매체비·대행 수수료·VAT 모두 포함, 매월 동일하게 전액 배분 |
| 계약 기간·총액 | 3개월, 부가세 포함 9,000,000원 |
| 수수료 | 월 순매체비의 15%, 원 단위 반올림, 회사 사규의 포함 업무 적용 |

| 추가 비용 | 승인 없는 추가 청구 없음 |
| 문서 성격 | 계약 전 제안·견적이며 계약 체결이나 집행 승인이 아님 |

위 요율·반올림 조건에 맞춰 순매체비를 산정하고 매체별 배분의 원 단위 잔액은 마지막 매체에 반영하세요. 세전 매체비와 부가세 포함 청구액을 혼용하지 마세요. 3개월 총액은 월별 청구액의 합으로 구하세요.

## 제공된 성과 가정

월별 CPC·CVR은 아래 계획값을 적용합니다. 매체별 배분은 제안자가 정합니다.

| 월 | 매체 | CPC | 구매 전환율(CVR) |
| --- | --- | --- | --- |
| 1개월차 | 네이버 검색·GFA 합산 | 500원 | 3% |
| 1개월차 | 메타 피드·스토리 합산 | 400원 | 1% |
| 2개월차 | 네이버 검색·GFA 합산 | 500원 | 3.5% |
| 2개월차 | 메타 피드·스토리 합산 | 350원 | 1.5% |
| 3개월차 | 네이버 검색·GFA 합산 | 500원 | 4% |
| 3개월차 | 메타 피드·스토리 합산 | 300원 | 2% |

- 예상 클릭=매체별 순매체비÷CPC, 예상 전환=클릭×CVR
- 구매 1건당 1개 판매로 가정하고 매출=예상 전환×39,000원. 필터 재구매·추가 구매는 제외
- 두 매체의 전환 중복은 없다고 가정. 실제 집행에서는 중복·추적 누락을 확인
- 월·누적 CPA와 ROAS는 합산 순매체비·전환·매출로 구할 것. 매체별 CPA의 단순 평균은 쓰지 말 것
- 중간값 반올림 없이 계산하고 최종 표시 단위를 명시. 1~2주 집행 후 실측으로 갱신할 계획을 적을 것

## 일정과 보고

- 계약 후 첫 주: 계정·추적 가능 여부·소재 확인 및 세팅
- 1개월차: 인지도·트래픽 집행과 초기 데이터 확인
- 2개월차: 저성과 소재·타겟 조정, 전환 중심 최적화
- 3개월차: 성과 점검과 후속 운영 제안
- 주 1회 간단 리포트와 월 1회 정식 리포트를 모두 제공
- 두 리포트 공통: 매체별 노출·클릭·CTR·CPC, 전환·CVR·CPA와 목표 비교, 집행액·잔여 예산, ROAS, 매체·캠페인별 예산 소진, 특이사항·다음 기간 개선 계획
