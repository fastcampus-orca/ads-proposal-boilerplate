# 요구사항

> 소재·수치·브리프 출처는 모두 설명용 가상 값입니다. 커피 입문 세트의 평가 준비용 요구사항 예시이며 실제 실행 결과가 아닙니다.

- 적용 회사 문서: `docs/about-company.md`·`docs/company-rules.md`·`docs/project-instructions.md`
- 대상 브리프: 온유커피 RFP(가상 문서, 별도 파일 없음)
