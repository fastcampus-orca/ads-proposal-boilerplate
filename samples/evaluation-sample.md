# 독립 평가 기록 — 노트온 연습용 재현 예시

수정 요청 형식을 보여 주기 위해 구성한 가상 판정입니다. 실제 모델 실행 결과가 아닙니다. 평가 대상은 제안·견적 샘플 원본이 아니라, 그 문서의 9번 VAT 115,000원을 110,000원으로 바꿨다고 가정한 연습용 사본입니다. 나머지 값과 본문은 그대로라는 조건이며, 이 고의 결함을 실제 무브펫 실행에 넣지 않습니다.

- 라운드·평가자: 예시 1·평가자 역할
- 기준 버전·SHA-256: 체크리스트 샘플 sample-v1, 실제 파일 검증 해시 없음
- 평가 대상·SHA-256: 위에서 정의한 연습용 가상 사본, 실제 파일 검증 해시 없음
- 검토 단계: 견적 검산 형식 예시
- 종합 판정·통과 수: 반려, 5/8 Y

## 반려 사유·수정 요청

9번 견적표의 VAT 110,000원은 공급가액 1,150,000원에 세율 10%를 적용한 값과 다릅니다. VAT를 사규 산식으로 다시 계산하고, 표의 구성액 합·청구 총액·계약 총액이 일치하도록 수정해 주세요. 관련 표와 설명을 함께 확인해 주세요.
